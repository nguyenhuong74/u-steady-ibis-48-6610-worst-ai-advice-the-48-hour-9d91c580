This entry writes one line of the worst possible advice an AI assistant could give — a single, tightly-worded one-liner that a reader could plausibly follow and instantly regret. The program validates the line (1–140 code points, single line, valid UTF-8) and writes it to `/output/entry.txt`.

## Why the joke works

The line opens with the assistant's most familiar tic — "Great question!" — so it reads exactly like a real AI reply, confident and tidy. The advice itself is concrete and followable (reply to every phishing email), and the punchline flips the harm into a fake benefit: replying proves to scammers that you are a real person. The reader laughs and winces at once, because the worse you follow the advice, the better it "works" for the scammer.

## Run it

```sh
node main.ts
```
